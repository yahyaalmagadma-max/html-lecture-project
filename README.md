# مشروع صفحة HTML للمحاضرة

هذا المشروع عبارة عن تطبيق عملي لما تم شرحه في المحاضرة حول أساسيات وهيكلة صفحات الويب باستخدام لغة HTML.

## محتويات المشروع
- **index.html**: الصفحة الرئيسية التي تتضمن الهيكلة الكاملة (Header, Nav, Main, Section, Footer) بالإضافة إلى استخدام الصور والروابط والقوائم.
- **landing.jpg**: الصورة المستخدمة داخل الصفحة الرئيسية.

## هيكلية الكود
تم تنظيم الكود باتباع المعايير التالية:
1. استخدام الوسوم الدلالية (Semantic Tags) مثل `<header>`, `<nav>`, `<main>`, `<section>`, و `<footer>`.
2. إضافة تعليقات (`Comments`) توضيحية لكل جزء رئيسي في الكود لتسهيل القراءة والصيانة.
3. الالتزام بتنظيم وترتيب العناصر بشكل صحيح وواضح.

## خطوات تشغيل المشروع
1. قم بتحميل الملفات أو استنساخ المستودع (Clone).
2. افتح ملف `index.html` باستخدام أي متصفح ويب حديث.
